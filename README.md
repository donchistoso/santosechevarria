for Santos Echevarria — automotive Finance & Insurance manager, Miami, FL,
33+ years in the field.

## Read first
- **`BRIEF.md`** — latest-session snapshot. Start here.
- **`GOALS.md`** — what this initiative is for and what done looks like.
- **`_source/facts-of-record.md`** — the only sanctioned source of facts.
